# Vijay Jain — Personal Website

A personal website built from [Shikun Liu’s Clarity template](https://github.com/lorenmt/clarity-template).

Open `index.html` to view the site. Edit the introduction, projects, writing, and experience in that file. Entries marked sample are placeholders.

The original template examples remain in `minimal.html` and `clarity.html`. Poppins and Charter fonts are bundled for offline viewing. `portfolio.css` contains the small portfolio-specific additions; the original Clarity layout remains in `assets/stylesheets/main_free.css`.
